## 교훈 목록

### 2026-10-10: 템플릿 복사 후 환경 점검

**상황**: Pagely 뼈대를 템플릿에서 복사해 시작
**실수**: ① 네이티브 모듈(better-sqlite3)이 Windows에서 빌드 실패 ② 템플릿의 `next lint`가 Next 16에서 제거돼 있었음
**교훈**: 네이티브 의존성은 설치 가능 여부를 먼저 확인하고 안 되면 순수 JS 대안을 쓴다. 복사 직후 `verify` 스크립트부터 돌려 템플릿 자체의 깨진 곳을 먼저 잡는다. 새 프로젝트 위치는 "프로젝트 안"이 아니라 형제 폴더인지 먼저 확인한다.

### 2026-10-10: useEffect 콜백은 값을 반환하지 않는다

**상황**: 에디터 화면에서 `destroy is not a function` 런타임 에러
**실수**: `useEffect(() => init(x), [...])`, `useEffect(fn, [...])`처럼 값을 반환하는 한 줄 화살표를 써서 반환값이 cleanup으로 취급됨. 테스트(jsdom)에서는 안 잡혀 브라우저에서야 발견
**교훈**: useEffect 콜백은 항상 `{ }` 블록으로 쓰고 cleanup이 필요할 때만 함수를 반환한다. `useEffect(fn, deps)`에 함수를 직접 넘기지 않는다. UI 변경은 테스트 통과만 믿지 말고 dev 로그(`.next/dev/logs`)도 확인한다.

### 2026-10-14: 셸 heredoc/도구 인자의 `\u` 이스케이프

**상황**: JSON-LD 직렬화 함수에 `'\u003c'`를 써야 했음
**실수**: Bash heredoc·Edit 인자에서 `\u003c`가 `\u003c`로 풀려 파일에 `'<'`로 저장됨. 테스트가 RED로 잡아서 발견, 세 번 재시도
**교훈**: 백슬래시 이스케이프가 들어가는 코드는 `String.fromCharCode(92)` 등으로 만든 뒤 파일에서 직접 확인한다. python은 이 환경에 없으니 node를 쓴다.
