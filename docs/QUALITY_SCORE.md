#### 테스트 역할 분담

| 구분                    | 도구                         | 위치           | 대상                                      | 실행                            |
| ----------------------- | ---------------------------- | -------------- | ----------------------------------------- | ------------------------------- |
| 단위·통합 (Vitest)      | Vitest + Testing Library     | `__tests__/`   | 로직, API 핸들러, 컴포넌트                | `npm run test` / `verify.sh`    |
| E2E (Playwright)        | Playwright                   | `e2e/`         | 실제 브라우저의 사용자 흐름 (2~3개부터)   | `npm run test:e2e` (별도)       |

- E2E는 `verify.sh` 완료 게이트에 넣지 않고 별도 스크립트로 돈다 (브라우저 설치·실행 비용). 안정화 후 게이트 편입 여부를 다시 정한다.
- E2E는 `DATA_DIR`을 임시 폴더로 잡아 실제 데이터를 건드리지 않는다.
- 새 흐름을 추가할 때: 로직이면 Vitest, 화면을 거쳐야 검증되는 흐름이면 E2E.
