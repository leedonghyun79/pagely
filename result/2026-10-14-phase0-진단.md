# /landing SEO 진단 (로컬 dev 기준, 2026-10-14)

| 레인 | 상태 | 근거 |
|---|---|---|
| SEO 기술 | ⚠️ | SSR OK(h1 1, h2/h3 14, HTML 97KB). title/description 있음. canonical·OG·Twitter·metadataBase 없음. robots.txt/sitemap.xml 404 |
| AEO | ❌ | FAQ 5개가 `<details>`로 SSR에 있으나 FAQPage JSON-LD 0건 |
| GEO | ❌ | llms.txt 404, JSON-LD 전무(Organization/WebSite/SoftwareApplication 없음) |
| LLMO | ⚠️ | 서비스 정의·사용법 문장은 본문에 있으나 엔티티(@id) 선언 없음 |
| NEO(네이버) | ⚠️ | 서치어드바이저 등록은 사용자 계정 필요. robots/sitemap 부재로 제출할 대상 자체가 없음 |
| 콘텐츠 | ❌ | /blog 404, 피드 없음 (이번 범위 아님) |

noindex: `<meta robots>`·`X-Robots-Tag` 모두 없음 → 사고 없음.
404: 없는 경로는 404 정상. `/lading`(오타) → 307 임시 리다이렉트.
'/' 메타는 기본값("Opennow", 짧은 설명)이고 /landing과 구분 안 됨.

## 우선순위
1. robots.ts / sitemap.ts (색인 대상 명시, /editor·/api·/preview 차단)
2. 메타 보강: metadataBase, canonical, OG, Twitter, 설명 길이
3. JSON-LD: Organization·WebSite·SoftwareApplication + FAQPage (FAQ 배열 단일 소스)
4. llms.txt
5. '/lading' 308 영구 리다이렉트
보류: OG 이미지(한글 폰트 필요), 서치어드바이저·GSC 등록(사용자 계정), 블로그
